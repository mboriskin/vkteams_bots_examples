## Примеры ботов для VK Teams

![VK Teams logotype](./resources/small_logo.png "logotype")

### Описание

[Боты](https://teams.vk.com/botapi/) - автоматизация взаимодействия VK Teams с любой другой инфраструктурой.

### Технологии

- Python
- [mailru-im-bot](https://github.com/mail-ru-im/bot-python)

### Как разворачивать простых ботов:

Запускать на отдельной машине основной python-файл с кодом бота. Можно в фоне. Можно с периодичностью через crontab.

### Как разворачивать сложных ботов:

Сделать бот как python библиотеку - см. [гайд](https://habr.com/ru/articles/760046/).

Запускать эту библиотеку отдельно в фоне, желательно в docker контейнере. Идеально - на отдельной виртуальной машине в облаке.
