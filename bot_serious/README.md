## Проект Serious Bot

### Описание

Бот-сервис для упрощения работы на полях в серьёзных рабочих процессах.

### Технологии

- Python
- Jira
- Gitlab

### Ответственный

m.boriskin

### Дополнительная информация

### Как работает бот:

Что можно сделать:
отправить боту команду `/status` или любой текст, кроме `/help`, `/insert` или `/contains`. Бот подскажет что делать дальше.

забрать коммиты из привязанного к Jira-тикету Merge Request в  Git ветку

```
/insert JIRATICKETKEY-8888 serious_branch
```

проверить Git-коммит в Git-ветке

```
/contains JIRATICKETKEY-8888 serious_branch
```

### Как разворачивается бот:

С помощью запуска pipeline и создания python бибилиотеки
